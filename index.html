🏆RANK, RANK.EQ

전체 점수 중에서 내 점수는 몇 등일까? 순위 구하기의 끝판왕!

RANK.EQ 함수는 전체 범위에서 특정 숫자의 순위(등수)를 구해줍니다.
(과거에 쓰던 RANK 함수와 완전히 똑같은 최신 버전 함수입니다. 동점자가 있으면 '높은 등수'를 같이 줍니다.)

=RANK.EQ(순위를구할값, 전체참조범위, [내림/오름차순])
  • 순위를 구할 값 : 내 점수가 있는 셀 하나 클릭!
  • 전체 참조 범위 : 비교할 전체 점수 범위를 드래그 (절대참조 $ 고정 필수!)
  • 0 또는 생략 : 점수가 가장 높은 사람이 1등 (내림차순)

📌 실습: 학생들의 성적 순위 구하기

B열의 점수를 자유롭게 바꿔보세요! 실시간으로 순위가 계산됩니다.
C열의 순위(결과) 셀을 클릭하면 수식에 사용된 범위가 색깔로 표시됩니다.
